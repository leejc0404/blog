## 0. 먼저 알아야 할 것 — 서버 봇 방어

검사 도중 두 서버가 **"One moment, please..." 챌린지**를 반환하기 시작했다. 확인된 사실:

- **GET은 통과, REST `POST`(글 수정)는 여러 IP·여러 경로(로컬 PC, 클라우드, 실제 크롬 브라우저)에서 전부 차단**된다.
- 즉 이건 IP 차단이 아니라 **REST 쓰기 요청을 막는 서버/플러그인 규칙**으로 보인다.
- 이 규칙이 계속 살아 있으면 **야간 자동 업로드 루틴(Draft 루틴의 WP 업로드)도 같은 이유로 실패**한다. 최근 며칠 새 글이 안 올라갔다면 원인이 이것일 가능성이 높다.
- 확인 위치: Cloudways 콘솔 → 해당 서버 → Security / Bot Protection, 그리고 WP 보안 플러그인 설정.

**결과: 차단은 일시적이었고, 클라우드 쪽 경로로 49개 글 수정이 전부 적용 완료됐다** (2026-09-05 심야). 다만 집 IP는 검사 시점에 두 서버 모두에서 챌린지에 걸렸었다 — 아침에 사이트나 wp-admin이 안 열리면 이 차단이 남은 것이니, 공유기를 재부팅해 IP를 바꾸거나 Cloudways 콘솔에서 차단 IP를 풀면 된다. 앞으로 전수검사를 돌릴 때는 동시 요청을 4 이하로 두고 간격을 두는 것이 안전하다.
